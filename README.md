# Harry AI – Restaurant Booking Agent for London

## 🇬🇧 About

Harry AI is an AI-powered restaurant booking agent designed to help users discover and book restaurants in London.

The goal is to make restaurant reservations simple, fast, and conversational.

## ✨ Features

- 🔎 Find restaurants in London
- 🍽️ Search by cuisine and preferences
- 📅 Choose date and time
- 👥 Select number of guests
- 💬 Conversational AI booking assistant
- 📍 Search restaurants by location
- ⭐ Help users compare restaurant options

## 🤖 AI Assistant

Harry AI is designed to understand natural-language requests such as:

> "Find me an Italian restaurant in Central London for two people tonight."

The assistant can then help the user find suitable options and proceed with the booking.

## 🎯 Project Goal

Build a practical AI restaurant booking agent that provides a simple and user-friendly booking experience for London restaurants.
